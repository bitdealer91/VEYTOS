# Known limitations and review priorities

No independent external audit completed. These are limitations and coverage findings, not a claim that all defects have been found.

1. **Compatible upgrades are custody authority.** Both publishers can change logic; operation-level no-seizure claims assume unchanged bytecode. Immutable policy is proposed, not applied.
2. **V2 collection approval is a security boundary.** Retained creator TransferRef can move escrowed assets. A Collection resource, direct owner check and ungated transfer flag cannot prove safe provenance. Registry and all marketplace settings share one admin. Revocation prevents new listings only; use V2/global pause to stop existing purchases. External movement/restriction can make seller cancellation fail. There is no generic rescue function.
3. **V1 historical support is conditional.** Only native TokenData maximum 1 and exact seller TokenId balance 1 are accepted; collection name recognition is insufficient. Mutable maximum can change after listing. Previously granted WithdrawCapability can act after cancel/buy returns the token to its recorded owner. Marketplace neither enumerates nor revokes those capabilities.
4. **Reimbursement is policy, not a measured per-transaction refund.** Source defaults: V1=0, V2=926400 octas, cap=10000000 each. Historical V1 acceptance configured 926400; it is not the initialization default. Different key/value lengths, gas payer sponsorship and network pricing can change net economics. Contract conserves gross independently; buyer transfers snapshot in addition. Mainnet calibration is unresolved and must not silently copy one testnet sample.
5. **Test quantity is not full coverage.** Matrix identifies missing adversarial rollback, complete pause combinations, event fields, malformed V1 variations, input/gas bounds, listing-ID exhaustion and seller-total overflow fixtures. Generic expected failures need tightening. Unit harness rollback is not independent committed-transaction evidence.
6. **Authority separation is proposed only.** No pause-only role, dedicated registry signer, on-chain timelock, multisig policy or admin renounce function is implemented in these modules. Compromised admin can redirect future fees or deny service; a lost quorum has no hidden recovery. Avoid promises beyond current APIs.
7. **Two framework pins and live governance.** Mainnet ABI/features and VM/storage semantics must be independently verified. Immutability does not freeze system modules. Testnet evidence has historical package addresses and is not mainnet release evidence.
8. **Persistent state and gas.** Terminal listing records remain; no V2 ObjectCore shell remains in current code. Drop metadata tables and mint counters persist. Maximum supply/batch gas benchmarks and adversarial state-growth limits remain review work.
9. **Off-chain services are not production evidence.** Provider credentials/accounts are unavailable; Phase 3B remains blocked. RPC, database/indexer, frontend, storage, secrets and incident operations require their own deployment validation. No deployment experiment is included here.
10. **User-level constraints.** Wallet cap is per signer and does not stop Sybil wallets. Royalties are honored here, not on arbitrary external transfers. Launchpad supports up to 100% royalty configuration, but marketplace refuses a sale with fee+royalty >= gross; such an NFT may be mintable yet unlistable. On-chain URI validation is syntax only, not CID/content availability verification.
11. **Accounting aliases and ambiguity.** A recipient may equal buyer/another recipient; gross allocation does not necessarily equal net wallet debit. Gas/refunds remain separate. Pending/unknown transactions require hash and state reconciliation, never automatic resubmission based on indexer absence.

Intentionally unsupported: semi-fungible/maximum-not-one V1; wrong/absent TokenId or missing data; nested V2 ownership; ungated-transfer-disabled V2; unreviewed V2 collections; invalid royalty fractions/payees or nonpositive seller proceeds; zero-price marketplace sales; auctions/offers/bundles/cross-chain settlement. Free launchpad mint remains supported through the same checks.
