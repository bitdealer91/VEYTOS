# VEYTOS reference study

Reviewed 2026-09-23: [OpenSea](https://opensea.io/) and
[Magic Eden](https://magiceden.io/ru), using current public pages and browser inspection.
No downloaded reference artwork, logos, CSS or proprietary assets are used.

OpenSea puts search above discovery and pairs large editorial collections with a
compact ranking surface. Its persistent navigation and distinct browsing sections
make discovery quick. Collection cards keep names, artwork and a small set of
numbers together. Learn the information hierarchy and progressive density.

Magic Eden's current surface uses prominent search, featured artwork and sortable
collection tables with aligned financial columns. Its short labels and strong row
identity help scanning. The wallet entry stays in the header. Learn consistency
between cards and tables and clear boundaries between browsing and transactions.

VEYTOS deliberately uses a compact horizontal header, warm neutral surfaces and a
vermilion accent. One ecosystem means no chain carousel or multi-chain navigation.
No token trading, packs, rewards, noisy feeds or unsupported financial columns.
Our top surface features a real Aptos drop; the historical collection section has
editorial prominence but stays honestly empty until discovery is implemented.

Mobile adaptation: prioritise collection identity, price and one action; secondary
numbers disappear rather than compressing columns. Filters wrap and search stays
available. Wallet selectors and transaction review use accessible native dialogs.
Reference mobile and signature flows were not fully exercised; VEYTOS receives its
own explicit breakpoint and wallet-state validation rather than assuming parity.
